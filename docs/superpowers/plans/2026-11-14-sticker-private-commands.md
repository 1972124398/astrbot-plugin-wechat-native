# 私聊准备表情库

用户要求将终端准备步骤改为微信私聊指令，继续复用当前 Native 账号和原生发送。
本次直接在当前工作区继续已授权的改动，不移动或清理此前尚未提交的工作。

## 交互与边界

- `/表情包` 显示帮助，`/表情包 同步` 同步 Saved 和已添加包。
- `/表情包 列表` 查看已添加包名称、ID及媒体就绪状态。
- `/表情包 下载 PACK_ID` 仅下载当前账号已添加的一个包到 Native 缓存。
- `/表情包 状态 JOB_ID` 只读核对本插件已保留的任务。
- 使用 AstrBot 管理员权限和当前 Native 可信私聊事件，群聊、普通用户、其他平台均不调用 API。
- 直接调用 HTTP API，不启动 shell/CLI，不导出本地目录，不添加包或恢复引用收藏。
- 下载与同步提交前持久化固定幂等键，重复消息、并发、重启只核对既有在途任务。
- 返回任务编号和明确状态，不把受理视为完成；下载完成后继续使用已有 find/send。
